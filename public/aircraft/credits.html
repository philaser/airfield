Aircraft artwork & scale

Each silhouette is normalized to its drawing bounds, then displayed with its model’s published wingspan and length, in metres. The map uses the same metre coordinates. There is no minimum visible aircraft size; only the invisible hit area is enlarged for selection.

The drawings are simplified model silhouettes, not engineering CAD. The 777-300ER is calibrated from 777-300 family artwork; the A350-1000 is calibrated from A350-900 family artwork. Overall footprints use the selected variant’s dimensions.

Artwork

  • A350, A380 and A320: tar1090 / dump1090 contributors, including pimlie’s refined Airbus artwork. GPL v2 or later. Changes: extracted silhouette paths, normalized bounds and calibrated physical dimensions. Original path data and adapted SVG files are included here.

Illustrative night lighting follows general FAA lighting colour conventions; positions and spacing are visual effects, not surveyed lighting data.

Expanded model library

The 39 dimensioned types include additional Airbus, Boeing, Embraer, CRJ and turboprop models. New fixed-wing artwork uses tar1090 family shapes calibrated to nominal model dimensions. The AS50 and EC35 rotorcraft drawings are original schematic rotor discs and fuselages, scaled to current H125 and H135 rotor diameter and D-value. They do not depict surveyed airframe outlines or individual variants.

Read the per-model dimensional catalog and primary source references. The A321ceo uses the family envelope shared with the A321neo; wingtip configuration can vary. Unsupported fixed-wing models retain dots. Unsupported helicopters use the tar1090 generic rotorcraft symbol, without claiming a calibrated footprint.

Model names and classifications: tar1090-db / Mictronics, public factual type dictionary retrieved 5 September 2026 (2,788 entries). No registration lookup service or additional API request is used. A model code is identified from the feed, not inferred from a callsign. Missing headings are shown upright with a dotted ring.
